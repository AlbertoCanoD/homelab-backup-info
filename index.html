HomeLab Backup · uso personal

Copias cifradas para un servidor doméstico.

HomeLab Backup es una configuración personal para crear y recuperar copias de seguridad de un servidor doméstico.

Cómo utiliza Google Drive

El sistema utiliza rclone para conectar con la cuenta de Google del propietario y gestionar los archivos de copia creados por la aplicación. Las copias se cifran con Restic antes de almacenarse en Google Drive.

La automatización y las pruebas de restauración siguen en preparación.

Privacidad

La política de privacidad explica qué acceso se solicita, cómo se utilizan los datos y cómo revocar el acceso.

Contacto

Para contactar con el responsable, consulta la dirección de soporte indicada en la pantalla de autorización de Google. También puedes abrir una incidencia pública en GitHub; no incluyas contraseñas, tokens ni datos privados.
